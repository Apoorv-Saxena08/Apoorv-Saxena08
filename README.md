### 🤖 [Recro AI — AI-Powered Interview Platform](https://github.com/Apoorv-Saxena08/Recro-AI)
> *Because practicing interviews alone is painful — so I built a solution.*

An end-to-end AI interview simulator. Upload your resume → get personalized questions → answer via voice → receive a detailed evaluation report. No generic Q&A banks. Real, context-aware interviews.

- Parses resumes using Node.js + Express, integrates **Google Gemini 2.5 Flash** for question generation
- Voice-based interaction with downloadable performance reports
- **10+ active users · 20+ mock interviews conducted**
- Stack: `React · Node.js · Express · MongoDB · Gemini API · Firebase`

### 🚇 [Delhi Metro Path Finder](https://github.com/Apoorv-Saxena08/Delhi-metro-path-finder)
> *DSA meets real-world utility.*

A visual, interactive route-finder for the Delhi Metro network. Computes shortest paths using **Dijkstra's Algorithm** and renders the route live on screen. Built to show that competitive programming isn't just for OJs — it solves real problems.

- Implements graph algorithms (Dijkstra's) on actual Delhi Metro network data
- Real-time visual route rendering
- Stack: `HTML · CSS · JavaScript · DSA`

### 🎓 [PRAVARTAK — Student Dropout Risk Prediction (SIH 2025)](https://github.com/Apoorv-Saxena08/PRAVARTAK)
> *Smart India Hackathon 2025 · Team Leader*

An early-warning system for educational institutions to identify at-risk students before they drop out. Analyzes attendance, academics, fee status, and activity data through an ML pipeline and surfaces color-coded alerts (Green/Yellow/Red) on a centralized mentor dashboard.

- Led a **6-member team** end-to-end: ideation → architecture → deployment
- ML pipeline using **Scikit-Learn** for risk scoring
- Stack: `Python · Flask · MongoDB · Scikit-Learn · Bootstrap · REST APIs`

**[→ GitHub](https://github.com/Apoorv-Saxena08/PRAVARTAK)**
